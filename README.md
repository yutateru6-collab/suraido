# suraido

高校生向け英文法解説スライドのデザイン・背景素材・Google Drive連携ルールを管理するリポジトリです。

## 入口
- `SKILL.md` — 作成時の正典
- `references/backgrounds.md` — Google Drive背景素材一覧
- `references/style-guide.md` — フォント・文字サイズ・色・レイアウト
- `references/google-drive-workflow.md` — Drive連携の手順
